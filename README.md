# 무량 · 無量 바둑

3D 없이 웹 페이지로 만든 온라인 바둑 사이트입니다. 서버 없이 정적 파일만으로 돌아가므로 GitHub Pages에 그대로 올리면 됩니다.

## 기능
- **로그인 · 회원가입**: 아이디(영문 소문자로 시작, 4~16자) + 비밀번호(6자 이상) + 닉네임 + 기력
- **프로필 설정**: 돌 색 아바타 6종 또는 사진 올리기, 닉네임 · 기력 · 한마디, 아이디 변경(바꾼 뒤 24시간이 지나야 다시 변경), 비밀번호 변경, 전적(승 · 패 · 승률), 최근 대국
- **방 만들기**: 상대(사람 / 무량 AI 입문 · 중급 · 고급), 판 크기(19 · 13 · 9줄), 내 돌(돌 가리기 · 흑 · 백), 대국 시간(무제한, 5 · 10 · 20 · 30분 + 초읽기 30초 3회), 덤, 한 수 물리기 허용 여부, 도전 직접 허락 / 자동 수락, 비공개 방(비밀번호)
- **방 들어가기**: 대국실 목록에서 「도전하기」 또는 「관전」, 「빠른 대국」(바로 앉을 수 있는 방을 찾고, 없으면 새 방)
- **허락하기**: 도전 신청 허락·거절, 한 수 물리기 · 계가 신청 · 다시 두기(흑백 바꿈) 요청을 상대가 허락하거나 거절
- **대국**: 패스(양쪽이 연달아 패스하면 자동 계가), 계가 신청, 기권, 시간패, 수 번호 · 좌표 표시, 착수 소리, 대국실 채팅, 수순, 관전자 목록
- **관전**: 진행 중인 대국을 축소 바둑판으로 보고 들어가 관전
- **기보실**: 끝난 대국 자동 저장(내 기보), 공개 기보, 명국 50국
  - 기보 보기: 처음 · 앞뒤 · 10수 이동 · 슬라이더 · 자동 재생 · 방향키, 판을 클릭해 변화도 두기
  - **공개하기 / 공개 취소**, **SGF 내려받기**, **이미지(PNG)로 저장**, SGF 불러오기, 공개·명국 기보를 내 기보에 담기
- **로비**: 접속자 목록(누르면 그 사람의 프로필과 공개 기보), 로비 채팅
- **계정 옮기기**: 프로필에서 계정 파일(.json, 비밀번호는 해시) 내려받기 → 다른 기기의 로그인 화면에서 불러오기

## 꼭 알아 두기 (서버가 없는 구조)
- 계정 · 기보는 **이 기기의 브라우저(localStorage)** 에 저장됩니다. 브라우저 데이터를 지우면 함께 지워집니다.
- 대국 · 관전 · 채팅 · 기보 공개는 접속한 사람끼리 **직접 연결**(Trystero P2P)해 주고받습니다.
  - 방은 방을 연 사람의 브라우저가 붙잡고 있으므로, 방장이 창을 닫으면 방이 닫힙니다.
  - 아이디가 겹치지 않는지는 이 기기와 지금 접속한 사람, 공개 기보 기준으로만 확인할 수 있습니다.
  - 공개 기보는 접속한 사람들끼리 서로 나눠 가지는 방식이라, 모두에게 똑같이 보이지 않을 수 있습니다.
- 모두가 같은 계정·순위·기보를 보게 하려면 나중에 Firebase · Supabase 같은 저장소를 붙여야 합니다.

## 올리기
저장소 맨 위에 `index.html`, `style.css`, `src/` 를 두고 GitHub Pages(Deploy from a branch · main · /(root))를 켜면 됩니다.

## 파일
- `index.html` · `style.css` — 화면
- `src/app.js` — 계정 · 방 · 대국 · 관전 · 기보 · 화면 전환
- `src/engine.js` — 바둑 규칙(착수 · 따내기 · 자충 · 패) · 계가 · 인공지능
- `src/worker.js` — 인공지능 · 계가를 따로 계산(화면이 멈추지 않게)
- `src/board.js` — 바둑판 그리기 · SGF 읽기/쓰기
- `src/famous.js` — 명국 기보 50국
